이 시제품에서 가능한 것

동네온 커뮤니티
GitHub와 Vercel로 정적 웹을 배포하고 Supabase를 연결하면 실제 이메일 인증과 키워드별 공유 채팅이 작동합니다. 연결 전에는 로컬 체험입니다.

순위는 여전히 예시입니다.
실제 지역별 1~100위 산정에는 별도의 수집·집계 시스템이 필요합니다. 뉴스·블로그 언급량을 실제 검색량으로 표현하지 않습니다. 콘텐츠 링크는 원문이 아닌 검색 결과 링크입니다.

지도 라이브러리가 차단되면 OpenStreetMap 임베드로 전환하며, 둘 다 차단되면 외부 지도 링크를 이용할 수 있습니다. 대체 지도에서는 경로 선이 표시되지 않습니다.

자동차 경로는 공개 OSRM 결과이며 실시간 교통 미반영입니다. 도보는 직선거리 기반 단순 추정입니다. 위치는 브라우저에 저장하지 않지만 경로 조회를 위해 OSRM에 전송됩니다.

Supabase 연결 시 닉네임·인증 계정·메시지는 서버에 저장됩니다. 채팅은 공개 열람되고 인증 사용자만 작성할 수 있습니다. 이메일은 채팅에 노출되지 않습니다.

운영 전 신고·차단, 스팸 방지, 보관 기간, 개인정보처리방침과 외부 데이터 이용 조건을 반드시 준비하세요.
